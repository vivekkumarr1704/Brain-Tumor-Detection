# Brain Tumor Detection using Deep Learning

This project implements a comparative study of YOLOv8, Faster R-CNN, 
Mask R-CNN, RetinaNet, and SSD-MobileNet for brain tumor classification 
using MRI images.

## How to Run
1. Create virtual environment
2. Install dependencies: python3 -m pip install -r requirements.txt
3. Run app: streamlit run interface/app.py
